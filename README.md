# Francesco Operetto

Personal website with teaching materials and educational tools for Mathematics and Physics.

Sito personale con materiali didattici e strumenti per l'insegnamento della Matematica e della Fisica.

## Dentro la rete / Inside the Network

Interactive educational simulator for exploring neural networks, forward propagation and backpropagation.

Simulatore didattico interattivo per esplorare reti neurali, forward pass e backpropagation.

- Online: https://francesco-operetto.github.io/dentro-la-rete/
- Repository: https://github.com/francesco-operetto/dentro-la-rete
